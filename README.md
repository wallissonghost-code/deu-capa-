# DEU CAPA — Revista Digital

Versão inicial de uma revista digital simples e responsiva para divulgação de participantes, ensaios, eventos e talentos.

## Estrutura inicial

- Capa da edição
- Destaque principal
- Galeria de participantes
- Perfil rápido em modal
- Seção "Como funciona"
- Chamada para solicitar participação
- Layout responsivo para celular

## Próximas etapas sugeridas

1. Inserir fotos e participantes reais.
2. Conectar o botão de participação ao WhatsApp ou Instagram.
3. Criar um painel simples para cadastrar participantes sem editar código.
4. Adicionar edições anteriores quando houver mais de uma publicação.
5. Publicar a versão final em hospedagem pública.
